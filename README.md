# Auto MPG Data Analysis

This project performs Exploratory Data Analysis (EDA) on the Auto MPG dataset using Python. It analyzes vehicle fuel efficiency based on features such as horsepower, weight, displacement, cylinders, origin, and model year.

## Features
- Data Cleaning
- KPI Calculation
- Fuel Efficiency Trend Analysis
- MPG by Origin Analysis
- Market Share Visualization
- MPG vs Weight Analysis
- MPG vs Horsepower Analysis
- Engine Distribution
- Correlation Heatmap

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

  
Insights
Fuel efficiency improves across model years.
Japanese cars generally have higher MPG.
Heavier vehicles usually have lower MPG.
Higher horsepower generally reduces MPG.
4-cylinder engines dominate the dataset.
